# Skills

Skill — Markdown-инструкция для агента. Не код Harness, не код сервера.
Вся предметная логика системы живёт здесь.

## Модель

```
Категория → Skill → назначается агенту → загружается в workflow/skills/
                                     → передаётся Deep Agents на этапе
```

Skill хранит: название, категорию, описание, Markdown, версию, хеш, активность.
Изменение текста увеличивает версию.

## Что описывает skill

1. Что нужно сделать и в каком порядке.
2. Какие команды проекта запускать для проверок.
3. Что считается готовым результатом.
4. Что делать при ошибке.
5. Какие файлы трогать нельзя.

## Категории MVP

| Категория | Примеры |
|---|---|
| Разработка | создание лендинга, React, FastAPI |
| Ресёрч | анализ конкурентов, подбор технологий |
| Тестирование | frontend-проверки, Python-проверки |
| Git | GitHub: commit и push, GitLab: commit и push |
| Деплой | Dokploy |
| Документация | README, отчёт |

Категории — данные, не enum в коде. Новая область (SEO, контент, аналитика)
добавляется созданием категории и skill'ов.

## Формат имени файла

`<категория>--<название>.md`, слаг в латинице:

```
workflow/skills/development--landing.md
workflow/skills/testing--frontend.md
workflow/skills/git--github-push.md
workflow/skills/deploy--dokploy.md
```

## Назначение и этапы

| Этап | Skills |
|---|---|
| Планирование | разработка, ресёрч, проектные инструкции |
| Реализация | разработка, тестирование |
| Проверки | тестирование |
| Публикация | git, деплой — только после `publish` |

Если у агента нет git- или deploy-skill, он заканчивает на `ready`:
ни push, ни deploy не выполняются.

## Версии и снимки

- Правка → версия +1, новый `content_hash`.
- При аренде задачи фиксируется снимок использованных skills.
- Задача всегда использует версию из снимка.

## Ограничения

- Запрещены секреты, пароли, API-ключи, токены, приватные SSH-ключи.
- Skill не даёт прав: доступ определяется токенами и окружением.
- Deploy-skill обязан требовать подтверждения публикации.
- Harness не исполняет Markdown — только передаёт агенту как инструкцию.
- Все реальные действия агента попадают в прогресс и отчёт.

## Проверка при сохранении

Сервер при создании и правке skill:

1. Проверяет размер и кодировку.
2. Ищет подозрительные паттерны (ключи, приватные ключи, токены) — предупреждает.
3. Считает `content_hash`.
4. Не публикует содержимое в логи.
