# Журнал решений

Один файл на значимое решение: `YYYY-MM-DD-<короткое-имя>.md`.

```markdown
# <Решение>

## Контекст
Что случилось и почему нужно решить.

## Варианты
1. ...
2. ...

## Выбор
Что выбрали и почему.

## Последствия
Что меняется в коде, документах, процессах.

## Открытые вопросы
Что осталось непроверенным.
```

Правила:

- Решение фиксируется в момент принятия, а не задним числом.
- Если решение отменено — файл не удаляется, добавляется пометка
  `Отменено <дата>, см. <файл>`.
- Решения по архитектуре, схеме БД, публикации и безопасности обязательны.
