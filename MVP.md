# MVP

Границы первой версии. Источник требований — [PLAN.md](PLAN.md).

## Вертикальный срез

Один сквозной путь, работающий целиком:

```
Telegram (голос)
→ задача в панели
→ Harness арендует задачу
→ Deep Agents строит план по skills
→ подтверждение плана в Telegram
→ реализация в worktree task/<id>
→ проверки из skills
→ отчёт с файлами и результатами тестов
→ приёмка
→ git push / Dokploy deploy по skills
→ итог в панели и Telegram
```

## Входит в MVP

| Блок | Минимум |
|---|---|
| Сервер | FastAPI, PostgreSQL, SQLAlchemy, Alembic, JWT-логин |
| Панель | 5 экранов: `/login`, `/projects`, `/projects/{id}`, `/tasks/{id}`, `/skills` |
| Telegram | текст, voice, audio; кнопки решений; уведомления |
| Транскрибация | один внешний провайдер через `TRANSCRIPTION_PROVIDER` |
| Skills | категории, карточки, версии, хеш, привязка к агенту, снимок на задачу |
| Harness | `init`, `run`, heartbeat, аренда, worktree, запуск Deep Agents |
| MCP | 11 инструментов из PLAN.md |
| Публикация | только после решения `publish` |

## Не входит в MVP

- Мультипользовательность и роли.
- Мобильное приложение.
- Редактор skills с подсветкой и предпросмотром.
- Автоматическое назначение skills.
- Очереди Redis/RabbitMQ/Kafka.
- WebSocket-обновления панели (только polling/перезагрузка).
- Несколько агентов на один проект одновременно.
- Собственный движок агентов.
