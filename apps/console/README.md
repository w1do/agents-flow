# Консоль оператора: проекты

React 18, TypeScript strict, Vite, shadcn/ui (Radix + Tailwind), TanStack Query,
React Router. Этап реализует только настройки проектов (3b.1–3b.7).

## Запуск

Нужны Node.js 22.12+ и pnpm 9.12.3. Из корня репозитория:

```sh
cd apps/console
pnpm install --frozen-lockfile
pnpm dev
```

Откройте адрес Vite и введите токен оператора. Dev-сервер проксирует `/api` на
локальный сервер (порт 8000); для другого адреса измените `server.proxy` в
`vite.config.ts`. Сервер запускается отдельно по инструкции `apps/server/README.md`.
Консоль не вызывает `agent init`.

После `pnpm build` статика лежит в `dist`. Хост должен отдавать `index.html` для
SPA-маршрутов и проксировать `/api` на API сервера с тем же origin. `pnpm preview`
позволяет просмотреть сборку, но не проксирует API. HTTPS и заголовки CSP
`default-src 'self'`, `X-Frame-Options`, `Referrer-Policy` настраиваются на хосте;
деплой в этот этап не входит.

Образ собирается из корня репозитория (контекст нужен для `packages/shared-types`):
`docker compose build console` (сервис `console` в `docker-compose.yml`, Dockerfile
`apps/console/Dockerfile`). Внутри образа nginx (`apps/console/nginx.conf`) отдаёт `dist`,
проксирует `/api/` и `/health` на сервис `server:8000` и слушает порт 80 без публикации наружу.

## Проверки

Все команды выполняются из `apps/console`:

```sh
pnpm lint
pnpm format:check
pnpm typecheck
pnpm test
pnpm build
```

`pnpm format` исправляет форматирование. Vitest + Testing Library проверяют
API-клиент, формы, вход, сохранение repo, ошибки и подтверждение отключения.
В тестах заменяется только HTTP-транспорт; серверные изменения не нужны.
Playwright smoke для канбана относится к отложенному этапу.

## Общие типы

Типы импортируются из `@harness/shared-types` (локальный пакет
`packages/shared-types`). Они генерируются из JSON Schema текущих Pydantic-моделей
`harness_shared.projects`, вручную контракты не поддерживаются.

Для генерации нужен Python с зависимостями `shared/pyproject.toml` (Pydantic v2):

```sh
pnpm types:generate
pnpm types:check
```

`types:check` повторяет генерацию и падает при расхождении; подходит для CI.
Если Python проекта отличается от системного, укажите интерпретатор через `PYTHON`.
Экспортёр живёт в `packages/shared-types`: серверный модуль экспорта схем на этом
этапе не добавляется.

## Переменные окружения

Имена: `HARNESS_ADMIN_TOKEN` (сервер), `PYTHON` (генератор типов, необязательно).
Frontend-переменных окружения нет. `.env` не требуется и Vite его не загружает.
Токен вводится в браузере, живёт только в памяти вкладки и забывается при выходе,
перезагрузке или 401. Он не попадает в URL, cookie, localStorage и sessionStorage.

## Поведение

Список включает `disabled` и обновляется каждые пять секунд. Редактирование читает
проект заново и отправляет только изменённые поля. При изменении repo передаётся
весь блок, включая текущий `access_ref`; очистка ссылки отправляет `null`.
Пустая команда тестов отправляется как `null`. `id` при редактировании доступен
только для чтения. Ошибки отображаются по известным кодам и именам полей без
значений из ответов сервера. Главные правила валидации остаются у сервера.

Отключение требует подтверждения: новые задачи и выдача настроек прекращаются,
задачи в работе продолжают выполняться.
