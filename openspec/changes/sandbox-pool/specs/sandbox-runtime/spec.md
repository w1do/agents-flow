## ADDED Requirements

### Requirement: Выбор песочницы по типу агента

Диспетчер SHALL выбирать свободную песочницу с типом агента задачи; песочница MUST выполнять одну задачу одновременно.

#### Scenario: Две песочницы

- **WHEN** две свободные песочницы `claude-code` и две задачи
- **THEN** задачи выполняются параллельно на разных песочницах

### Requirement: Удаление с подтверждением

`delete_sandbox` SHALL требовать `confirm=true` и MUST отказывать для песочницы с активной задачей.

#### Scenario: Занятая песочница

- **WHEN** оператор удаляет песочницу с активной задачей
- **THEN** отказ с указанием задачи
