## ADDED Requirements

### Requirement: Закреплённые версии

Bootstrap SHALL устанавливать точные версии CLI из профиля и MUST завершаться ошибкой при несовпадении установленной версии.

#### Scenario: Несовпадение версии

- **WHEN** в песочнице установлена другая версия `claude`
- **THEN** bootstrap переустанавливает нужную или завершается ошибкой
