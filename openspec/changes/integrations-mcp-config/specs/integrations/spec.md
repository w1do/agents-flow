## ADDED Requirements

### Requirement: Секреты только ссылками

Читающие инструменты SHALL возвращать для секретов только ссылки и MUST NOT возвращать значения.

#### Scenario: Чтение конфигурации

- **WHEN** оператор вызывает `list_mcp`
- **THEN** в ответе ссылки вида `secret://…`, значений нет

### Requirement: Конфиг MCP для агента

`get_mcp_config` SHALL возвращать MCP-серверы workspace задачи, а значения секретов MUST передаваться агенту только через окружение при активации.

#### Scenario: Активация с интеграцией

- **WHEN** workspace использует CRM-интеграцию
- **THEN** в env агента есть значение ключа, в файлах песочницы его нет
