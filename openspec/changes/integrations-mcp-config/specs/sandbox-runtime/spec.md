## MODIFIED Requirements

### Requirement: Изоляция агента от настроек репозитория

Агент SHALL запускаться без чтения hooks и MCP-серверов из настроек проекта в рабочем каталоге: только
пользовательские настройки чистого профиля песочницы и MCP-конфигурация харнесса. MCP-конфигурацию харнесса MUST
генерировать сервер при каждом запуске агента из раздела MCP платформы, встроенного `project-memory` и `agents-flow`;
агент MUST запускаться только с ней (`--strict-mcp-config`). Переменные `ANTHROPIC_API_KEY` и `ANTHROPIC_AUTH_TOKEN`
MUST NOT передаваться процессу агента.

#### Scenario: Hook в репозитории

- **WHEN** в worktree лежит `.claude/settings.json` с hook и `.mcp.json` с посторонним сервером
- **THEN** hook не выполняется, посторонний сервер не подключается

#### Scenario: Сервер раздела MCP виден агенту

- **WHEN** в разделе MCP есть сервер, и агент запускается
- **THEN** этот сервер подключён, а сервер из `.mcp.json` worktree — нет
