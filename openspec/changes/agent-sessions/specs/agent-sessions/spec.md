## ADDED Requirements

### Requirement: Смена сессии по порогу

Если контекст последнего ответа достиг 120k, сессия SHALL закончиться на ближайшей границе отрезка; при 150k MUST останавливаться немедленно с handoff без summary агента.

#### Scenario: Целевой порог

- **WHEN** на границе отрезка контекст 125k
- **THEN** сессия закрыта с причиной `threshold`, новая стартует с handoff

#### Scenario: Жёсткий предел

- **WHEN** контекст 152k посреди отрезка
- **THEN** процесс остановлен, handoff построен сервером из git

### Requirement: Одна сессия за раз

Новая сессия SHALL стартовать только после завершения процесса старой и записи handoff (или через 3 минуты без него).

#### Scenario: Handoff не пришёл

- **WHEN** старая сессия завершилась, агент не записал handoff за 3 минуты
- **THEN** сервер строит handoff сам и запускает новую сессию
