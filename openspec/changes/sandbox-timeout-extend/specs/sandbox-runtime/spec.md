## ADDED Requirements

### Requirement: Песочница живёт, пока идёт задача

Сервер SHALL продлевать таймаут песочницы, пока задача активна, и MUST повторять обращения раз в 10 минут при недоступности.

#### Scenario: Временная недоступность

- **WHEN** exec недоступен 15 минут, затем восстановился
- **THEN** сервер читает файл статуса и продолжает с того же этапа
