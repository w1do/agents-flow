## ADDED Requirements

### Requirement: Опасные инструменты требуют подтверждения

Инструмент `stop_task` SHALL требовать `confirm=true` и без него MUST возвращать `confirm_required` без изменений.

#### Scenario: Остановка без подтверждения

- **WHEN** оператор вызывает `stop_task` без `confirm`
- **THEN** возвращается `confirm_required`, задача не меняется

### Requirement: Управление задачами оператором

Операторские инструменты SHALL выполнять те же операции сервиса, что и Telegram-кнопки, с теми же проверками переходов.

#### Scenario: Повтор задачи

- **WHEN** оператор вызывает `retry_task` для задачи в `error`
- **THEN** задача возвращается в `backlog`, событие записано с источником оператора
