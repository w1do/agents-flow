## ADDED Requirements

### Requirement: Активация песочницы под задачу

Перед запуском агента система SHALL возобновить песочницу, закрепить её за задачей, выдать креды только на эту
задачу, обновить репозиторий и создать worktree на ветке `task/<task_id>` от указанной базы. Повторная
активация той же задачи MUST возвращать текущее состояние без повторной подготовки. Песочница MUST NOT
закрепляться за двумя задачами одновременно.

#### Scenario: Песочница занята

- **WHEN** песочница выполняет задачу A, а в очереди задача B
- **THEN** задача B остаётся в очереди, пока песочница не освободится

#### Scenario: Повторная активация

- **WHEN** worker перезапустился и снова активирует ту же задачу
- **THEN** worktree и ветка не пересоздаются, агент не запускается второй раз

### Requirement: Запуск агента без клиента

Агент SHALL запускаться командой в песочнице через API провайдера, в фоне, с выводом в файл потока и итогом
в файл статуса. Сервер MUST определять завершение агента по файлу статуса и коду выхода.

#### Scenario: Агент завершился

- **WHEN** процесс агента завершился с кодом 0
- **THEN** сервер читает статус, сохраняет код выхода и переходит к следующему этапу задачи

#### Scenario: Превышено время

- **WHEN** агент работает дольше лимита времени задачи
- **THEN** процесс останавливается, задача переходит в `error` с причиной «превышено время»

### Requirement: Креды не остаются в песочнице

Секреты SHALL передаваться в песочницу только в окружении конкретной команды и MUST NOT записываться в файлы
песочницы. Bootstrap-скрипт MUST NOT содержать секретов.

#### Scenario: Проверка диска

- **WHEN** после запуска агента в песочнице ищут значение выданного токена в `~` и в каталоге репозитория
- **THEN** значение не найдено

### Requirement: Пауза только после очистки

После завершения задачи система SHALL удалить worktree и локальную ветку, отозвать токен задачи и только при
успехе очистки поставить песочницу на паузу. При ошибке очистки песочница MUST переходить в `error` без паузы.

#### Scenario: Очистка не удалась

- **WHEN** удаление worktree вернуло ненулевой код
- **THEN** песочница в статусе `error`, пауза не вызывается, причина записана

### Requirement: Ручная пауза и возобновление

Оператор SHALL иметь одну команду для паузы и одну для возобновления песочницы из конфигурации.
Пауза MUST отказывать, если за песочницей закреплена активная задача.

#### Scenario: Пауза занятой песочницы

- **WHEN** оператор вызывает паузу во время активной задачи
- **THEN** команда отказывает с указанием задачи
