# Proposal: spec-drift

> Расхождение спецификации и зеркала. Волна 4 (после MVP), см. PLAN.md.

## Why

Источник правды — файл в репозитории; `spec_items` может разойтись с ним (C13).

## What Changes

- При старте задачи сервер сравнивает `tasks.md` изменения с `spec_items`
- Побеждает репозиторий: зеркало обновляется
- Каждое расхождение пишется в журнал

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `spec-planning`: добавляются требования (ADDED): Побеждает репозиторий.
