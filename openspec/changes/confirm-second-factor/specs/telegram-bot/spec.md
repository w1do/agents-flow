## ADDED Requirements

### Requirement: Код для опасных команд

Опасная команда из Telegram SHALL выполняться только после кнопки «Подтвердить» и верного одноразового кода; неверный код MUST отклонять команду.

#### Scenario: Неверный код

- **WHEN** владелец вводит неверный код после «Подтвердить»
- **THEN** команда не выполняется, бот сообщает об ошибке

#### Scenario: Блокировка

- **WHEN** введено три неверных кода подряд
- **THEN** опасные команды недоступны 15 минут
