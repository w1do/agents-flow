## ADDED Requirements

### Requirement: Обнаружение зависания

Если heartbeat активной задачи не приходил 5 минут и процесс агента не найден, задача SHALL перейти в `stalled` с уведомлением.

#### Scenario: Агент пропал

- **WHEN** процесс агента завершился без статуса, heartbeat нет 5 минут
- **THEN** задача в `stalled`, владелец получает сообщение
