## ADDED Requirements

### Requirement: Один администратор

При первом старте сервер SHALL создать администратора из ENV и хранить только хеш пароля; дальнейшие изменения ENV MUST NOT перезаписывать пароль.

#### Scenario: Первый старт

- **WHEN** база пуста, заданы `ADMIN_EMAIL` и `ADMIN_PASSWORD`
- **THEN** создан администратор с хешем пароля

### Requirement: Сброс пароля на сервере

Пароль SHALL сбрасываться только командой на сервере.

#### Scenario: Сброс

- **WHEN** выполнена `harness-server reset-password`
- **THEN** вход возможен с новым паролем, старые сессии отозваны
