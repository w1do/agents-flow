## MODIFIED Requirements

### Requirement: Выбор проекта кнопкой

Текст, который маршрутизатор отнёс к классу `work` (уверенно, после кнопки «Сделать задачу» или по запасному пути),
SHALL создавать задачу `plan` в статусе `choosing` и сообщение с кнопкой на каждый предложенный workspace: не больше
трёх, самый вероятный первым, а при запасном пути — все workspace из `harness.yaml`. Нажатие кнопки MUST переводить
задачу в `planning` с выбранным workspace и записывать выбор в `routings`. Задача MUST NOT запускаться без нажатия.

#### Scenario: Выбор workspace

- **WHEN** владелец пишет «добавь экспорт в CSV» и нажимает кнопку проекта «Магазин»
- **THEN** задача получает workspace «Магазин» и статус `planning`, в сообщении появляется строка этапа

#### Scenario: Повторное нажатие после выбора

- **WHEN** владелец нажимает другую кнопку проекта у задачи уже в `planning`
- **THEN** workspace не меняется, бот отвечает подсказкой «проект уже выбран»

#### Scenario: Кнопка неизвестного проекта

- **WHEN** приходит нажатие кнопки с workspace, которого нет в `harness.yaml`
- **THEN** статус задачи не меняется, бот отвечает подсказкой «проект не найден»

#### Scenario: Выбор записывается в решение маршрутизации

- **WHEN** владелец нажимает кнопку проекта «Демо-проект» у задачи, созданной по запасному пути
- **THEN** в `routings` этой задачи `chosen_workspace_id` равен `demo`
