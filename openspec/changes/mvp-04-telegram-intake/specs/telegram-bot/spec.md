## ADDED Requirements

### Requirement: Только владелец и подписанный webhook

Сервер SHALL принимать обновления Telegram только с верным секретом webhook и только из чата `TELEGRAM_CHAT_ID`.
Запрос без верного секрета MUST получать `401`. Сообщения из других чатов MUST игнорироваться без ответа
пользователю и без сохранения их текста.

#### Scenario: Неверный секрет

- **WHEN** на webhook приходит запрос с неверным `X-Telegram-Bot-Api-Secret-Token`
- **THEN** сервер отвечает `401` и ничего не создаёт

#### Scenario: Чужой чат

- **WHEN** приходит сообщение из чата, отличного от владельца
- **THEN** сервер отвечает `200`, бот ничего не отправляет, задача не создаётся

### Requirement: Идемпотентный приём

Повторная доставка обновления с тем же `update_id` и повторное нажатие кнопки с тем же `callback_query.id`
MUST NOT создавать новую задачу, новую активацию или новое событие.

#### Scenario: Повторная доставка

- **WHEN** Telegram дважды присылает одно обновление с текстом задачи
- **THEN** создаётся ровно одна задача

### Requirement: Выбор проекта кнопкой

Текст задачи SHALL создавать задачу `plan` в статусе `choosing` и сообщение с кнопкой на каждый предложенный
workspace. Нажатие кнопки MUST переводить задачу в `planning` с выбранным workspace. Задача MUST NOT
запускаться без нажатия.

#### Scenario: Выбор workspace

- **WHEN** владелец пишет «добавь экспорт в CSV» и нажимает кнопку проекта «Магазин»
- **THEN** задача получает workspace «Магазин» и статус `planning`, в сообщении появляется строка этапа

#### Scenario: Повторное нажатие после выбора

- **WHEN** владелец нажимает другую кнопку проекта у задачи уже в `planning`
- **THEN** workspace не меняется, бот отвечает подсказкой «проект уже выбран»

### Requirement: Одно сообщение на задачу

Этапы задачи SHALL отображаться в одном сообщении, которое редактируется; каждая новая строка имеет вид
`Задача [<краткое название>] (<этап>)`. Текст, уходящий в Telegram, MUST проходить фильтр секретов.

#### Scenario: Два этапа

- **WHEN** задача переходит в «начата», а затем в «готова, MR создан»
- **THEN** в чате одно сообщение с двумя строками этапов
