## ADDED Requirements

### Requirement: Настройки задачи неизменны

Задача SHALL использовать настройки workspace на момент старта; изменения MUST применяться только к следующим задачам.

#### Scenario: Смена команды тестов

- **WHEN** команду тестов изменили во время активной задачи
- **THEN** задача использует прежнюю команду, следующая — новую
