# Proposal: task-limits

> Лимиты задачи. Волна 3 (после MVP), см. PLAN.md.

## Why

Задача не должна бесконечно тратить время и токены (C3).

## What Changes

- Лимиты на задачу: время, число ходов, токены (настройки workspace)
- Превышение → остановка агента, `error` с причиной, сообщение «превышен бюджет»
- Проверка на границе отрезка и по таймауту exec

## Capabilities

### Modified Capabilities

- `budget`: добавляются требования (ADDED): Остановка по лимиту.
