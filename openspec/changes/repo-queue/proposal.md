# Proposal: repo-queue

> Очередь на репозиторий. Волна 5 (после MVP), см. PLAN.md.

## Why

Параллельные задачи в одном репозитории конфликтуют (B3).

## What Changes

- Одна активная задача на репозиторий; остальные ждут в `backlog`
- Rebase на свежую базу перед push; конфликт → `error` с причиной
- Параллельность для разных репозиториев

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `delivery-gates`: добавляются требования (ADDED): Одна задача на репозиторий, Конфликт при rebase.
