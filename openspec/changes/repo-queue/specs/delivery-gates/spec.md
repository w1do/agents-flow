## ADDED Requirements

### Requirement: Одна задача на репозиторий

Диспетчер SHALL NOT брать задачу, если в её репозитории уже есть активная задача.

#### Scenario: Две задачи одного репо

- **WHEN** задача A активна в репо X, задача B в `backlog` для X
- **THEN** B ждёт, пока A не завершится

### Requirement: Конфликт при rebase

Конфликт при rebase на базу SHALL переводить задачу в `error` с перечнем конфликтующих файлов.

#### Scenario: Конфликт

- **WHEN** rebase задачи даёт конфликт в двух файлах
- **THEN** задача в `error`, причина перечисляет два файла
