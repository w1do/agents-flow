## ADDED Requirements

### Requirement: Периодический снимок

Во время активной задачи сервер SHALL раз в минуту фиксировать незакоммиченную работу WIP-коммитом и пушить его, если изменения есть и в них нет секретов.

#### Scenario: Изменения есть

- **WHEN** за минуту агент изменил два файла
- **THEN** в `task/<id>` новый WIP-коммит, в базе запись снимка

#### Scenario: Секрет в изменениях

- **WHEN** в изменениях найден токен
- **THEN** снимок не пушится, событие о блокировке без значения
