## ADDED Requirements

### Requirement: Bootstrap по одноразовой ссылке

Bootstrap-скрипт SHALL отдаваться только по одноразовому токену и MUST NOT содержать секретов; повторное использование токена MUST отклоняться.

#### Scenario: Повторная ссылка

- **WHEN** ссылка bootstrap использована второй раз
- **THEN** сервер отвечает `410`

### Requirement: Версии профиля

Изменение профиля SHALL создавать новую версию; песочница MUST хранить версию профиля, с которой собрана.

#### Scenario: Обновление профиля

- **WHEN** оператор меняет список репозиториев
- **THEN** создаётся версия N+1, песочницы обновляются при следующей активации
