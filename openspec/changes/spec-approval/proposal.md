# Proposal: spec-approval

> Утверждение спецификации кнопкой. Волна 4 (после MVP), см. PLAN.md.

## Why

После MVP спецификация должна ждать утверждения, прежде чем задачи пойдут в работу (D-04).

## What Changes

- Настройка workspace `spec_approval` (по умолчанию включена)
- Задачи плана создаются в `backlog`, но диспетчер не берёт их до утверждения
- Кнопки «Утвердить» / «Отклонить» в итоге планирования; «Отклонить» → задачи в `trash`

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `spec-planning`: добавляются требования (ADDED): Задачи ждут утверждения.
