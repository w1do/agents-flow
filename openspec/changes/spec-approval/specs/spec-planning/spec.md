## ADDED Requirements

### Requirement: Задачи ждут утверждения

При включённом утверждении задачи реализации SHALL NOT браться в работу до нажатия «Утвердить»; «Отклонить» MUST переводить их в `trash`.

#### Scenario: Утверждено

- **WHEN** владелец нажимает «Утвердить»
- **THEN** задачи плана становятся доступны диспетчеру

#### Scenario: Отклонено

- **WHEN** владелец нажимает «Отклонить»
- **THEN** задачи плана в `trash`, ветка плана остаётся
