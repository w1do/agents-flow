## ADDED Requirements

### Requirement: Только чтение через MCP

Экраны наблюдаемости SHALL получать данные только через инструменты MCP со скоупом `read` и MUST NOT менять состояние.

#### Scenario: Канбан

- **WHEN** администратор открывает канбан
- **THEN** задачи сгруппированы по статусам, данные получены вызовами `list_tasks`
