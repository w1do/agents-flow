## ADDED Requirements

### Requirement: Выбор провайдера песочницы

Система SHALL поддерживать провайдеров песочницы `novita` и `vps` за одним протоколом и выбирать провайдера по
конфигурации. Сервисы, worker и CLI MUST NOT зависеть от конкретного провайдера. Отсутствие секрета выбранного
провайдера MUST останавливать старт с именем переменной, без значения.

#### Scenario: Провайдер VPS в конфиге

- **WHEN** в `harness.yaml` указано `sandbox.provider: vps` и блок `sandbox.vps`
- **THEN** worker и CLI работают с песочницей по SSH теми же командами, что с Novita

#### Scenario: Нет ключа SSH

- **WHEN** выбран `vps`, а `VPS_SSH_PRIVATE_KEY` не задан
- **THEN** старт worker завершается ошибкой с именем `VPS_SSH_PRIVATE_KEY`

### Requirement: Песочница на VPS

Провайдер `vps` SHALL выполнять команды и работать с файлами по SSH от пользователя из конфигурации,
проверяя ключ хоста по закреплённому отпечатку. Секреты команды MUST передаваться не в аргументах команды.
Пауза и продление MUST быть пустыми операциями.

#### Scenario: Чужой ключ хоста

- **WHEN** отпечаток ключа хоста не совпадает с `sandbox.vps.host_fingerprint`
- **THEN** соединение разрывается, команда не выполняется, ошибка `host_key_mismatch`

#### Scenario: Секрет не виден в списке процессов

- **WHEN** запускается команда с `CLAUDE_CODE_OAUTH_TOKEN` в env
- **THEN** значение токена не встречается в аргументах удалённой команды

#### Scenario: Bootstrap без нужных программ

- **WHEN** на VPS нет `node`
- **THEN** bootstrap завершается с кодом 3 и сообщением «нет node», ничего не устанавливая от root
