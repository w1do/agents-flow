## ADDED Requirements

### Requirement: Продолжение на другой песочнице

Задача `stalled` SHALL продолжаться на другой свободной песочнице с ветки задачи и последнего чекпоинта; старая песочница MUST помечаться `error`.

#### Scenario: Песочница потеряна

- **WHEN** песочница задачи не отвечает дольше лимита
- **THEN** задача активна на другой песочнице, старая в `error`, владелец получает сообщение «сорвана, перенесена»
