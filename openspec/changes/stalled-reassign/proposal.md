# Proposal: stalled-reassign

> Перенос сорванной задачи. Волна 5 (после MVP), см. PLAN.md.

## Why

Если связь с песочницей не восстановилась, задача должна продолжиться на другой с последнего снимка (ТЗ §7).

## What Changes

- Задача `stalled` после лимита попыток уходит на свободную песочницу
- Новая песочница: fetch, checkout `task/<id>`, контекст последнего чекпоинта
- Старая песочница помечается `error`

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `sandbox-runtime`: добавляются требования (ADDED): Продолжение на другой песочнице.

## Impact

- Зависит от: `agent-heartbeat`, `sandbox-pool`, `harness-snap`.
- Ссылки: ТЗ §7, §10.1 (потеря песочницы).
- Затрагивает ARCHITECTURE.md (разделы по теме) и, при новых инструментах, docs/mcp-agents-flow.md.

## Не входит

- Автоматическое удаление сломанной песочницы
