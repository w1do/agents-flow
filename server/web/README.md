# Agents Flow — панель

```bash
npm ci
npm run build
npm test
```

Сборка проверяет TypeScript и создаёт `dist/`. FastAPI автоматически раздаёт её
из `server/web/dist`, включая прямые переходы на маршруты панели.
Если сборки нет, сервер продолжает обслуживать API.

Панель и FastAPI должны работать с одного origin: браузер отправляет
HttpOnly-cookie сессии только same-origin запросам; cookie также использует
`SameSite=Strict`.
По умолчанию API вызывается по относительному пути с текущего origin.
`VITE_API_BASE` необязателен и принимает только путь-префикс либо URL с тем же
origin, без `/api/v1`:

```bash
VITE_API_BASE="/gateway" npm run build
```

Значение с другим origin вызывает понятную ошибку при инициализации клиента.
Vite не загружает `.env` файлы; настройка передаётся через окружение процесса.
Браузерный вход устанавливает HttpOnly-cookie `session`; JWT не попадает в
JavaScript. Выход удаляет cookie, а ответ 401 возвращает пользователя на `/login`.
Все остальные экраны требуют действующую сессию.
Данные обновляются каждые 15 секунд и кнопкой «Обновить».

Harness подключается одноразовым кодом с экрана проекта. Команда использует
базовый URL API, код вводится по запросу CLI и не включается в команду.
Код показывается до истечения срока либо до нажатия «Скрыть код».
`merged` означает разрешённую публикацию; её результат поступает отдельным
событием Harness и отображается на экране задачи.

